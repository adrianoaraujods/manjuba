# Tarefa

Esse projeto tem o objetivo de criar o site de uma barbearia moderna.

A implementação deve seguir o fluxo:

1. Fluxo
2. Wireframe
3. UI no Figma
4. Protótipo navegável
5. HTML/CSS

## Etapa 1 — Fluxo do usuário

### Fluxo Principal

Home → Serviços → Serviço → Profissionais → Galeria → Agendamento → Confirmação

### Fluxo Secundário

Home → Agendamento → Confirmação

## Etapa 2 — Wireframe

Os wireframes não podem ter preocupação estética, a ideia é apenas representar o _layout_ e fluxo do usuário.

- Home;
- Sobre;
- Serviços;
- Detalhes de serviço;
- Profissionais;
- Galeria;
- Planos/mensalidades;
- Agendamento;
- Confirmação.

> O formulário de agendamento pode ser apenas visual.

## Etapa 4 — Protótipo navegável

- Hero [Agendar] → Agendamento
- Serviços
- Barbeiros
  - Barbeiro X [Agendar] → Agendamento
- Planos
- Agendamento [Agendar Horário] → Confirmação

## Etapa 5 — Implementação

O protótipo no Figma deve ser implementado utilizando apenas HTML + CSS, focando nos pontos:

- HTML
- CSS
- Flexbox
- Grid
- Media Queries
- HTML semântico
